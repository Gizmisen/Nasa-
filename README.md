# COSMOLAB 3 — Mission Control 🚀

Educational browser game about designing and operating a space mission.

## Play
**[Launch COSMOLAB in your browser](https://gizmisen.github.io/Nasa-/)** (available after GitHub Pages is enabled and the deployment workflow completes).

The playable game is the root **index.html** and works in Chrome, Edge or Firefox without installation. Language: Russian / English. Saves are local to each browser, not stored on GitHub.

## Gameplay
- Base management, resources and planning
- Research and scientific laboratory
- Rocket engineering and design trade-offs
- Crew assignments, condition and teamwork
- Earth orbit, Moon and Mars missions
- Mission events, risk decisions and surface exploration

## Hosting
The [GitHub Actions workflow](.github/workflows/deploy-pages.yml) publishes the root HTML automatically when main changes. In repository **Settings → Pages**, choose **GitHub Actions** as the source if it has not been enabled. Review the workflow under the Actions tab.

## Source archive
This repository currently includes the standalone production HTML game. The expanded source archive, preview assets and presentation/video files are available separately in the COSMOLAB project package. They have not all been transferred to GitHub yet.

Project language: HTML, CSS, JavaScript; no backend required.
